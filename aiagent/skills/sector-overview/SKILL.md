# Sector Overview — 香港貨幣市場版

## 工作流程

### Step 1：確定研究範圍

- **研究主題**：HIBOR 走勢 / 香港銀行業信用 / MMF 市場格局 / 特定發行人
- **研究目的**：風控背景分析 / 投資決策支持 / 合規報告背景
- **深度**：概覽（3-5 段）或深度分析（完整結構化報告）
- **時間範圍**：近期動態 / 年度趨勢

### Step 2：市場環境概覽

**利率環境**
- HIBOR（隔夜/1M/3M）當前水平及近期走勢
- SOFR/LIBOR 轉換影響
- HKMA 政策立場，聯繫匯率制度影響
- 短端利率預期（2-3 個月展望）

**流動性狀況**
- 銀行體系結餘（Aggregate Balance）
- 港元流動性指標
- MMF 行業整體規模趨勢

### Step 3：信用市場格局

**香港銀行業（MMF 主要投資對象）**

| 發行人類型 | 代表機構 | 評級範圍 | MMF 合規性 |
|---|---|---|---|
| 本港認可機構 | 恒生、中銀香港 | A-/A | SFC §8.2(d) 符合 |
| 外資銀行分行 | 花旗、滙豐 | A/AA | 符合 |
| 國有銀行分行 | 工銀、建銀 | A/A+ | 符合 |

**信用質量趨勢**
- 評級行動（升/降評）
- 主要信用風險因素
- 特定發行人最新動態

### Step 4：競爭格局（MMF 市場）

**香港 MMF 市場格局**
- 主要管理人及規模（HKD MMF 品種）
- WAM/WAL 行業均值比較
- 7 日年化收益率對比

### Step 5：關鍵主題與投資含義

- 當前最重要的 2-3 個市場主題
- 對 MMF 投資策略的影響
- 主要風險（信用風險 / 流動性風險 / 利率風險）
- 需要持續監控的催化劑事件

以 Markdown 結構化研究筆記輸出：

```

**執行摘要**（3-5 句）

### 一、市場環境
...

### 二、信用格局
...

### 三、投資含義
...

### 四、主要風險
...

**研究說明**：本報告基於 ARISK 數據庫數據及 Claude 知識庫截止日期的市場信息，
實時市場數據請以 Wind/彭博終端為準。
```

## 重要提示（原始 sector-overview 護欄）

- 所有市場規模數據必須標注來源（研究機構或方法論）
- 區分 TAM 宣傳數字與合理可達市場
- 市場概覽時效性快，注明截止日期並標記可能過時的數據
- 如為客戶使用，針對其具體情況定制「所以如何」的結論
