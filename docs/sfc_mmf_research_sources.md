## 研究關鍵結論摘要

### ✅ 高可信度確認指標

| 監管指標 | 數值 | 來源 |
|---------|------|------|
| 加權平均期限 WAM | ≤ 60天 | UT Code §8.2(f)（2019年起，前為90天）|
| 加權平均存續期 WAL | ≤ 120天 | UT Code §8.2(f) |
| 單一工具剩餘期限 | ≤ 397天（政府/公共證券≤2年）| UT Code §8.2(f) |
| 日流動資產 DLA | ≥ 7.5% NAV | UT Code §8.2(n)；通函24EC64 |
| 週流動資產 WLA | ≥ 15% NAV | UT Code §8.2(n)；通函24EC64 |
| CNAV基金DLA（擬議） | ≥ 15% NAV | 諮詢文件25CP10（尚未生效）|
| CNAV基金WLA（擬議） | ≥ 50% NAV | 諮詢文件25CP10（尚未生效）|

### ❓ 未確認 / 需直接查閱原文

| 監管指標 | 狀態 |
|---------|------|
| 偏離度（Shadow Price Deviation）具體閾值 | SFC **未設定明確數值**（與內地±0.25%/±0.5%不同）；需採用公允價值估值 |
| 單一發行人集中度上限 | 需直接查閱UT Code §8.2原文，二手引用存在矛盾 |
| 槓桿比率上限 | UT Code通過投資限制間接控制，非明確比率規定 |
| 壓力測試頻率/情景要求 | 原則性要求，具體數值未見於已核實來源 |
| 信用評級具體代碼（A-1/P-1等）| UT Code要求「高質量」，無明確評級代碼規定 |
