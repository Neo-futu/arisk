# ARisk Platform  阿雷斯 智能风控与投资分析系统 简要描述文档

文档目的：明确“智能风控 + 投资组合分析 + Agent 能力”的需求范围、建设路径与风险控制。

## 背景与目标

公司在基金管理中，既需要稳定的风险控制能力，也需要面向投研与管理层的组合分析能力。当前平台通过分层架构基础（frontend 前端/ backend 后端/ 6_entry 入口/ 2_processing 固定业务计算/ 3_skills 技能/ 4_mcp 知识库连接），逐步落地。实现将行业经验和业务发展中涉及投资分析和风控相关业务开展活动，数字化沉淀到该系统。

目标：

1. 建立标准化的智能风控报表体系，支持日常与月度管理。
2. 开发投资组合分析核心模块，形成统一口径的数据与指标输出。
3. 将 Agent 能力用于对话查询、报表解释、定时任务编排，提升业务响应效率。
4. 在不推翻现有系统边界的前提下增量落地，保证可验证、可维护。

## 现状问题

1. 风控指标、业绩分析、报表输出在流程上仍需建立完善，需不断开发维护。
2. 从“数据查询 -> 指标计算 -> 结论解释”依赖人工和后续测试，效率受限。
3. 业务侧需要更灵活的对话式能力，但对口径一致、结果追溯有更高要求。
4. MCP 连接能力已具备，但在统一启停、运维规范、使用约定上仍需完善。

## 分层解决方案

围绕现有平台，采用“投资业务的确定性计算为核心，Agent 做编排与交互”的方案：

1. 展示与对外入口层（frontend + backend）
- 提供统一 Web 入口与权限控制。
- 对外 API 收口，保障接口与安全策略一致。

2. Agent 执行层（6_entry + aiagent + platform_agent）
- Agent Chat：自然语言查询、解释与追问。
- Agent 编排：风控报表生成、任务触发、状态回传。
- 定时任务：按日/周/月自动运行风险与报表流程。

3. 计算与业务规则层（2_processing + 3_skills）
- 2_processing：作为核心指标唯一计算来源（VaR、WAM、WAL、流动性、集中度、最大回撤等）。
- 3_skills：沉淀业务规则与分析模板，支持可治理、可迭代的技能体系。

4. 连接与数据层（4_mcp + 1_datastorage）
- 4_mcp：统一连接内部数据与外部行情数据（internal / wind / gateway）。
- 1_datastorage：提供数据库、缓存与持久化保障。

5. 投资组合分析能力范围（本期重点）
- 组合概况：规模、资产分布、期限结构、集中度。
- 业绩简报：阶段收益、基准对比、核心结论摘要。
- 风险指标：VaR、波动、回撤、流动性、合规阈值状态。
- 组合持仓：资产明细、前十大、信用与行业暴露。
- 绩效归因：收益来源拆解（资产、期限、信用、策略维度）。
- 投资月报：标准化月度输出（管理层可读版本）。
- Agent 相关能力：对话式风控报表、定时任务、Agent Chat 追问解释。

## 预期收益

1. 报表效率提升：常规风控与投资分析报告可标准化产出。
2. 口径一致性提升：指标计算、报表模板、对话解释同源。
3. 响应效率提升：业务可通过 Agent Chat 快速获取“数据 + 解释 + 下一步建议”。
4. 运维可控性提升：统一启停与分层监控降低排障复杂度。

## 三阶段落地节奏

### 阶段一：可用版（1-2 个迭代）

1. 打通核心指标与基础风控报表链路（日常可用）。
2. 交付组合概况、风险指标、组合持仓三类高频分析页面/接口。
3. 上线 Agent Chat 基础能力（查询 + 简报 + 解释）。

### 阶段二：稳定版（2-3 个迭代）

1. 补齐业绩简报、绩效归因、投资月报模块。
2. 建立定时任务体系（日报、周报、月报）与失败重试机制。
3. 完善 MCP 与 Agent 运行监控、日志追溯、告警机制。

### 阶段三：扩展版（持续迭代）

1. 扩展更多基金/策略场景与模板。
2. 增强风险预警与异常解释能力（规则 + 历史对比）。
3. 建立技能治理流程（评审、版本、回滚、下线）。

## 风险与控制

1. 指标口径偏差风险
- 控制：核心指标统一由 2_processing 输出，Agent 不重算核心值。

2. 对话结果稳定性风险
- 控制：关键业务场景必须回落到确定性工具结果并保留来源引用。

3. 数据连接与外部依赖风险
- 控制：MCP 采用 gateway + fallback 机制，保障可用性。

4. 多组件运维复杂度风险
- 控制：统一启动脚本、健康检查、冒烟验证与排障手册标准化。

5. 技能知识质量风险
- 控制：技能入库前审核，避免占位技能、重复内容或错误规则进入生产知识库。

## 汇报结论

本方案 `arisk-platform` 增量落地，不追求“一步到位全智能”，而是先保障业务可用与稳定交付，再逐步提升智能化能力。

结论要点：

1. 短期：可交付风控报表与核心组合分析能力。
2. 中期：形成“报表 + 分析 + Agent Chat + 定时任务”的闭环。
3. 长期：建设可治理、可扩展、可持续演进的智能风控与投资分析平台。
