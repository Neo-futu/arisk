# MMF 合規核查技能

## 核查依據

**法規**：《單位信託及互惠基金守則》（2019年1月版）第8.2章  
**PDF**：https://www.sfc.hk/-/media/TC/assets/components/codes/files-current/zh-hant/codes/section-ii-code-on-unit-trusts-and-mutual-funds/section-ii-code-on-unit-trusts-and-mutual-funds.pdf

## 核查流程

### Step 1：基本定義核查（第8.2(a)條）
確認基金投資標的僅限於：
- ✅ 短期存款（bank deposits, CDs）
- ✅ 高質素貨幣市場工具（CP, TB, BA, short-term notes）
- ✅ 符合第8.2章的其他 MMF（≤10% NAV）

### Step 2：期限核查（第8.2(f)條）
```
WAM ≤ 60 天        [第8.2(f)條]
WAL ≤ 120 天       [第8.2(f)條]
個別工具 ≤ 397 天   [第8.2(f)條]
政府證券 ≤ 2 年     [第8.2(f)條 + 第7.5條]
```

### Step 3：集中度核查（第8.2(g)條、第8.2(g)(a)條）
```
單一實體工具+存款：
  一般情況          ≤ 10% NAV   [第8.2(g)條]
  重要財務機構       ≤ 25% NAV   [第8.2(g)(i)條]
  政府及公共證券同批  ≤ 30% NAV  [第8.2(g)(ii)條]
  < USD 1M 存款     豁免         [第8.2(g)(iii)條]

同集團合計：
  一般情況          ≤ 20% NAV   [第8.2(g)(a)條]
  重要財務機構       ≤ 25% NAV   [第8.2(g)(a)條注(2)]
```

### Step 4：資產類型限制核查
```
資產抵押證券        ≤ 15% NAV   [第8.2(j)條]
其他 MMF           ≤ 10% NAV   [第8.2(i)條]
逆回購（同一對手方）≤ 15% NAV   [第8.2(k)(ii)條]
正回購收取現金      ≤ 10% NAV   [第8.2(k)(i)條]
借貸（臨時）        ≤ 10% NAV   [第8.2(h)條]
```

### Step 5：流動性核查（第8.2(n)條）
```
每日流動資產       ≥ 7.5% NAV  [第8.2(n)條]
每週流動資產       ≥ 15% NAV   [第8.2(n)條]
```

### Step 6：信貸質素核查（第8.2(e)條 + 第7.36(j)條附註(1)）
所有工具須為「高質素」，評估維度：
- 信貸評級（A-3/F3/P-3 或以上）
- 流動性狀況（可在合理時間以合理價格變現）
