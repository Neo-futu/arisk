  一、现有压力测试实现分析（原理解答）

  利率变化（report_03_mmf/42_stress_result.sql）：+50bp 久期近似法 压力市值 = 市值 × (1 − 久期 × 0.005)；浮息债久期 = 0.5×剩余全期 + 0.5×距下次付息日；存款/现金/逆
  回购利率敏感度为 0。

  变现系数：按资产类别硬编码（存款=0、浮息债=0.05、政府债/CD=0.2、信用债=0.8），修正压力损失 = 压力损失 × 变现系数。

  市场交易量：既有实现（investment_analysis_liquidity_stress.py）只有静态变现天数映射（CD=3 天、政府债=5 天……），完全没有 ADTV 概念。
